# Kompas-guides

Trin-for-trin-guides til Kompas' kurser. Siden vises med GitHub Pages.

- `index.html` er selve siden
- `data/guides.json` indeholder guiderne
- `media/` indeholder skærmbilleder og videoer

Guiderne bygges og redigeres i Kompas Guidebygger på claude.ai. Denne kopi opdateres, når der kommer nye guides.
